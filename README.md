# Jones Kicks Premium Ecommerce UI

A complete front-end ecommerce prototype built with plain HTML, CSS and JavaScript. React is not used.

All 20 sneaker photographs from the original Jones Kicks catalogue are included in this download. The hero, logo, product and contact/social image assets are bundled locally in `assets/images`, so the UI does not rely on the original website image host.

The original website did not publish prices. The starter prices in this UI are editable design placeholders and must be confirmed by the store owner before launch.

## Open the UI

Open `index.html` in a browser. You can also serve the folder with VS Code Live Server or any static web server.

The included GitHub Pages workflow publishes the site automatically whenever the `master` branch is updated.

## Admin UI demo

- Open the Admin link in the header or use `#/admin`.
- Email: `admin@joneskick.com`
- Password: `admin123`

The demo credentials, catalogue changes, orders and visitor count are browser-local UI features. They are intentionally not production security or server storage.

## Included customer experience

- Premium responsive homepage and hero slider
- Full 20-item sneaker catalogue
- Search, category filters and price sorting
- Product details and quick-view modal
- EU size selection from 40 to 45
- Wishlist and persistent shopping bag
- Delivery phone and address collection
- Checkout, payment handoff demonstration and order confirmation
- About and contact pages
- AOS scroll effects and Animate.css transitions

## Included admin experience

- Dashboard with views, orders, order value and catalogue totals
- Add, edit and remove sneakers
- Update price, previous price, picture, stock and description
- Upload a small product image in the prototype
- View customer orders and delivery details
- Update order fulfilment status
- Configure the future order-notification email
- View local prototype traffic analytics

## Backend phase required for production

Real admin authentication, shared database storage, cloud image uploads, Paystack payment processing, email notifications, server-side order handling and accurate cross-device analytics will be connected during backend development.
